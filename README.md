# Blog-Website

A simple blog website developed using **PHP and HTML**.  
This project demonstrates basic blog functionalities including displaying posts, searching posts, filtering by categories, and a simple sign-up interface.

---

## 📌 Project Overview

Blog-Website is a lightweight web application built to understand the fundamentals of PHP-based web development.  
It includes multiple pages for navigation, post viewing, searching, and basic user interaction.

This project is suitable for beginners who want to learn:

- Basic PHP structure  
- Multi-page website development  
- Server-side scripting  
- Simple blog system workflow  

---

## 🚀 Features

- 🏠 Homepage displaying blog posts  
- 📖 View individual post details  
- 🔎 Search posts by keyword  
- 🗂 Filter posts by category  
- 👤 Simple Sign-Up page  
- 🧭 Reusable navigation bar  
- 📄 About page

- (Optional) MySQL for database integration  

---

## ⚙️ Installation & Setup

1. Install XAMPP / WAMP / LAMP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache (and MySQL if using a database).
4. Open your browser and visit:

   http://localhost/Blog-Website/
